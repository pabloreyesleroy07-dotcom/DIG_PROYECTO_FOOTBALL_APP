# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [4.1.0] - 2026-04-22
### Added
- **Wiki Centralized Hub**: Created comprehensive docs ecosystem (`Developer_Documentation.md`, `Devlog_LinkedIn.md`).
- **Interactive API HTML**: Automated docstring generation yielding localized `.html` maps via PyDoc3.
- **GitHub Release Package**: Public standalone deployment wrapping up Linux binaries with MIT Licensing logic formalized.

## [4.0.0] - 2026-04-21
### Added
- **Military-Grade Security (`PyArmor`)**: Total bytecode obfuscation for backend routes and proprietary data extraction heuristics.
- **XOR Cryptography Key Safeguard**: Implementation of `config.py` dynamic base-64/XOR decoding mechanisms to eliminate `API_KEY` plaintext exposure in the codebase.
- **Executable Distribution**: Shipped standalone PyInstaller ELF binaries (`FootballStats_Secure`) with internal dependencies and persistent relative `data/db/` mapping.

## [3.0.0] - 2026-04-21
### Changed
- **Architectural Paradigm Shift (Async I/O)**: Deprecated synchronous Python `requests` logic. Migrated to `aiohttp` and `asyncio` for high-throughput, parallel data extraction.
- **Clean Architecture Implementation**: Entire codebase modularized into structured layers (`/api`, `/core`, `/data`, `/docs`).
- **RESTful Routing**: Decoupled monolithic files into distinct endpoints (`/api/dashboard`, `/api/generate`) yielding better OT vs IT interaction speeds.

## [2.0.0] - 2026-04-20
### Added
- **Dark Premium UI Engine**: Refactored the core HTML GUI from rudimentary structures to an advanced, fully decoupled static UI engine (Stacked sections, fluid scrolling).
- **Interactive Data Widgets**: Implemented a floating dock navigator and dynamic data-collapsible accordions for managing massive daily match reports.
- **Backend-Frontend AJAX Bridge**: Rewrote JS fetching methods preventing page-reload bottlenecks (`fetchReports`, `loadReport`, `generateBtn`).

## [1.0.0] - 2026-04-18
### Added
- **Initial Algorithm Conception**: Heuristic scanner capable of querying sports REST APIs to compare corner/goals algorithms for betting value optimization.
- **Persistent Local Database**: Implemented raw JSON parsing logic dictating predictions and outcomes.
